# Security policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue.

Use GitHub's **Security → Report a vulnerability** flow when private vulnerability reporting is available for this repository. Include:

- the affected version or commit;
- the affected Chrome version and operating system;
- clear reproduction steps;
- the expected and observed security impact; and
- any suggested mitigation, if known.

Do not include real passwords, API keys, access tokens, private Prompt contents, or other user secrets in a report. Use synthetic test data.

If private reporting is unavailable, open a public issue requesting a private contact channel without including vulnerability details.
